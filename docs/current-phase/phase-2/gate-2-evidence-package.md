## Package purpose

This package is the P6 evidence register. It traces every admitted behavior represented by a Phase 2 acceptance question through the complete chain:

```text
MVP boundary
-> parent system
-> journey stage
-> behavior contract
-> design expression
-> technical/data owner
-> validation question
```

The acceptance ID is the stable join key between the behavior contract and its validation question. The design expression records where the approved behavior is made observable without adding a new state, owner, route, or delivery rule.
