# Active Execution Logs

This directory contains only current operational logs. Historical July decisions, friction, inbox, and merge records are preserved under [docs/11-archive/execution/logs/](../../11-archive/execution/logs/).

Append-only evidence, capture, and decision records. For every commit, update the daily developer log and the active monthly narrative together; the monthly entry must not call unmerged work shipped.

| Log | Purpose |
|-----|---------|
| [inbox.md](../../11-archive/execution/logs/inbox.md) | Historical scratch UI/UX fix ideas |
| [friction-log.md](../../11-archive/execution/logs/friction-log.md) | Historical dogfood evidence |
| [developer-log/](./developer-log/) | Personal daily timeline (WIP, lessons) — not product authority |
| [july-log.md](../../11-archive/execution/logs/july-log.md) | Historical July session narrative |
| [decision-log.md](../../11-archive/execution/logs/decision-log.md) | Historical product-level decision collection; new consequential decisions use [Decision Records](../../08-decisions/decision-records.md) |
| [unmerged-branch-queue.md](../../11-archive/execution/logs/unmerged-branch-queue.md) | Historical founder-led priority queue |

**Pipeline:** inbox → bounded delivery or runbook → factual evidence → [Review Records](../../09-reviews/review-records.md) / [Post-Release Learning Records](../../09-reviews/post-release-learning-records.md) → decision or roadmap follow-through where warranted.
