## Template rules

- Templates are not live records and must not be used as evidence until copied and customized.
- The current sprint and gate checklist are the source examples; update a template only when the active example establishes a better reusable pattern.
- Layout is intentionally flexible. The Founder may explicitly add, improve, rename, reorder, or remove sections for the phase or gate.
- Keep the template status distinct from an active record: use `TEMPLATE — REFERENCE ONLY` until the file is copied into a real phase or sprint.
- Preserve the applicable authority links, evidence expectations, owner, status, dates, and final decision fields when customizing.

## Founder customization

Before using a template, record any explicit changes in the new document:

```markdown
## Founder Customization
- Add:
- Improve:
- Remove:
- Reason / authority:
```

Do not change a current phase record merely to make it match the template. Current work follows the active record; future work starts from the template.
