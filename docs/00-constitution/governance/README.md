## Decision flow

```
New or changed work
    → canonical product, feature, and engineering documents (scope and contract)
    → ENGINEERING.md / CODE_STANDARDS.md (current M2 implementation context)
    → GATES.md (current ship context)
    → Decision Records (consequential choice)
    → Review or post-release learning record (assessment and learning)
```
