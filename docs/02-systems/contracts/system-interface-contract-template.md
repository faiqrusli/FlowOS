# System Interface Contract Template

Non-normative starter artifact. Copy this file into `02-systems/contracts/` with a descriptive name. Govern the resulting contract through [Documentation Architecture](../../00-constitution/documentation-architecture.md) and the relevant system documents.

```text
Status: Draft | Active | Superseded | Archived
Authority: Shared semantic contract between [System A] and [System B]
Owner: [Role]

Children: [Feature contracts, delivery designs, or architecture documents]
Last reviewed: YYYY-MM-DD
Review trigger: [Event]
```
