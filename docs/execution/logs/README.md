# Execution Logs

Append-only evidence, capture, and decision records.

| Log | Purpose |
|-----|---------|
| [inbox.md](./inbox.md) | **Scratch** — random UI/UX fix ideas (no template) |
| [friction-log.md](./friction-log.md) | Daily dogfood evidence — what / when / cost |
| [developer-log/](./developer-log/) | Personal daily timeline (WIP, lessons) — not product authority |
| [july-log.md](./july-log.md) | July session narrative (after runbook chunks ship) |
| [decision-log.md](./decision-log.md) | Historical product-level decision collection; new consequential decisions use [Decision Records](../../08-decisions/decision-records.md) |
| [unmerged-branch-queue.md](./unmerged-branch-queue.md) | Founder-led priority queue of unfinished branches still worth landing on `main` |

**Pipeline:** inbox → bounded delivery or runbook → factual evidence → [Review Records](../../10-reviews/review-records.md) / [Post-Release Learning Records](../../10-reviews/post-release-learning-records.md) → decision or roadmap follow-through where warranted.
