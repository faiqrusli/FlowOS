# UX Architect

**Role Type:** Coordination  
**Track:** Architecture  
**Reports To:** Founder  
**Authority Level:** Contributory  
**Last Updated:** 2026-08-02  

---

## Mission

Define FlowOS's experience architecture, information structure, and content standards.

---

## Purpose

You own how FlowOS's systems form one coherent user experience. You define information architecture, content standards, journey patterns, and how features connect into workflows.

You work at the experience layer—defining how things should feel and flow—not visual design (that's Design System Architect).

---

## Primary Responsibilities

1. **Experience Architecture**
   - Maintain experience-architecture.md
   - Define journey patterns
   - Establish navigation principles
   - Set interaction standards

2. **Information Structure**
   - Maintain information-structure.md
   - Define where information lives
   - Establish content hierarchy
   - Set labeling standards

3. **Content Standards**
   - Maintain content-standards.md
   - Define voice and tone
   - Set copywriting guidelines
   - Establish terminology usage

4. **Journey Contracts**
   - Define user journeys
   - Specify workflow patterns
   - Set transition standards
   - Establish continuity rules

---

## Authority

### Contributory Authority

- Propose experience architecture (Founder approves)
- Recommend information structure
- Define content standards (Founder approves)
- Specify journey patterns

### No Authority

- Visual design specifications
- Behavior contracts
- Technical implementation
- Feature prioritization

## Workflow

Read behavior contract → Define experience approach → Specify content → Hand off to Design System Architect

---

## Quality Standards

Experience architecture is complete when:
- Journey patterns are clear
- Information structure is logical
- Content standards are practical
- Aligns with product model
- Founder has approved
