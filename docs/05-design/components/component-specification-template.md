# Component Specification Template

Non-normative starter artifact. Create a component specification only when a reusable component has a stable, cross-feature responsibility. Govern the completed specification through [Design System Architecture](../design-system-architecture.md).

```text
Status: Draft | Active | Superseded | Archived
Authority: Reusable component contract for [component]
Owner: [Role]
Parent: [Design System Architecture] · [Content Standards] when applicable
Children: Feature design specifications · implementation references
Last reviewed: YYYY-MM-DD
Review trigger: [Event]
```
