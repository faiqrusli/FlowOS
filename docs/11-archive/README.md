## What "Archive" Means

**11-archive/** contains documentation from the past:
- Completed milestone work (M0-M5)
- Old design iterations
- Superseded strategic plans
- Historical runbooks
- Old execution logs
- Completed phases (will include phase-0, phase-1, etc. as they complete)

**Key principle:** Archive is READ-ONLY reference, not for active work.
