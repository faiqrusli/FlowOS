- Reorganization summaries document major changes

**After phase completes:**
- Archive entire `phase-N/` folder to `docs/11-archive/phases/phase-N/`
- Create next `phase-N+1/` folder
- Maintain clean structure for current work

**This keeps current-phase/ focused on NOW, with complete history preserved.**
